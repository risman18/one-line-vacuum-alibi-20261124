## The entry

`main.py` (Python 3, standard library only) writes one line — a robot vacuum's
deadpan excuse for missing a spot — to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`):

> My sensors report the crumbs have unionized. One crumb is dirt; a hundred is a picket line, and I do not cross picket lines.

124 characters, one line, valid UTF-8.

## Run

```sh
python3 main.py
```
